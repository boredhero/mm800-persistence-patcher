# Security and responsible reporting

Use the repository's GitHub issues for technical bug reports and responsible
security reports. Do not attach stock firmware, full-device backups, EEPROM
dumps, patched binaries, or other proprietary device artifacts to an issue.

Include the device model, stock application hash, operating system, and the
smallest reproducible description of the problem. Include hashes rather than
firmware contents whenever possible.

For accidental proprietary-material publication, open an issue titled
`[takedown]` without repeating the material. The maintainer will remove current
content and address repository history and generated artifacts as appropriate.

No response-time guarantee or warranty is offered.
